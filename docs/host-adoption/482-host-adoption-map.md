# OpenHuman adoption map for tinyagents#482

This change moves the request-level media loop into
`tinyagents_harness::multimodal::MediaRequestModel`. The host keeps authority,
product selection, and host-specific presentation behind the seams below.

| Concern | TinyAgents API and OpenHuman replacement | Behavior to preserve in the host | Verification recipe |
| --- | --- | --- | --- |
| Request preparation, scope, limits, and history | Replace the request walk in `crates/openhuman-core/src/attachments/provider.rs::AttachmentModel::prepare` with `MediaRequestModel::new(inner, config, scope_for_request, resolver, extractor)`. In the synchronous `scope_for_request(&State, &mut ModelRequest) -> Result<Scope, String>` callback, normalize host `[ATTACHMENT:…]` transcript markers on the disposable copy, then consume `take_request_scope(&mut request.metadata)` and return `AttachmentAccessScope`. The callback runs before counting/history indexing, including requests without a user message, and must not perform source I/O. Configure `max_historical_media_items: 8` and `with_history_fallback` for safe omission and recovery. | Keep `resolve_path`, `secure_open`, channel restrictions, URL/DNS/credential policy, selected-model profile construction, and limits-cache lookup in the host (`attachments/provider.rs`, `attachments/host.rs`, and `attachments/legacy.rs`). Preserve latest-turn count/hard-disable errors; historical-only media under a hard disable makes zero resolver calls and degrades to safe placeholders. The generic wrapper counts each marker and each typed block as a history item, resolves newest items first, retains prose and successful neighboring refs when an older ref fails, and never sends a per-request scope carrier to the inner model. | Use TinyAgents `multimodal::request::tests`: `hard_zero_rejects_before_any_source_read`, `hard_zero_also_blocks_media_only_present_in_history`, `ordinary_count_limit_is_checked_before_resolving_any_marker`, `historical_media_budget_bounds_reads_and_replaces_older_items`, `historical_marker_budget_selects_only_the_newest_references_in_a_text_block`, `historical_text_recovers_each_failed_marker_without_losing_prose_or_valid_media`, `trusted_preparer_normalization_is_counted_before_resolution`, `trusted_preparer_consumes_carrier_when_request_has_no_user_message`, and the concurrent scope/request-metadata tests. Retain host tests for path authorization, channel restrictions, marker normalization, and exact config mapping. |
| Native media, fallback context, and host annotations | Replace `AttachmentModel::prepare`'s native/fallback rendering and `provider_fallback.rs::fallback` block walk with `MediaRequestModel`'s capability-gated media conversion, `TextExtractor`, bounded archive listing, and non-vision fallbacks. Keep host config-mapping tests and a parser-enabled integration test that verifies its configured extraction behavior without a real backend. |

## TinyAgents request-level regression coverage

Run `cargo test -p tinyagents-harness --features multimodal multimodal::request::tests`
for the request-wrapper suite. It verifies invoke and stream preparation on
disposable requests, errors and cancellation without canonical-history
mutation, concurrent immutable scope isolation, metadata consumption, hard
zero, raw-marker limits, bounded typed and marker history, per-marker recovery,
native/fallback behavior, PDF extraction, safe annotations, archive inspection,
and per-attachment Unicode-safe truncation.
